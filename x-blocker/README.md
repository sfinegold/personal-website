# X Pause

Chrome extension. Every time you open x.com (or twitter.com), a full-screen
countdown blocks the page for 10 seconds. Then the page is shown.

## Install

1. Open `chrome://extensions`.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and select this `x-blocker` folder.

## Change the delay

Edit `BLOCK_SECONDS` in `block.js`, then click the reload icon on the
extension card in `chrome://extensions`.
